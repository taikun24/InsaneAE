# InsaneAE

AE2 の制限を大きく拡張するアドオンです。最大 8E までのストレージおよびクラフトストレージ、16 スレッドの壁を超える並列クラフトユニット、
32 本を超えるチャンネルを伝送するケーブル、クラフトをまとめて処理する CPU を追加します。

前提として MEGA Cells が必要です。また、化学物質セルを使用する場合は Applied Mekanistics、FE セルを使用する場合は AppliedFlux、DISK を使用する場合は AE2 Things (液体・化学物質の DISK はさらに AE2 MEGA Things) が必要になります。
