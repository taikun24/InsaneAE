# InsaneAE

AE2 の上限を外すアドオンです。8E までのストレージとクラフトストレージ、16 スレッドの壁を越える並列クラフトユニット、
32 本を超えるチャンネルを運ぶケーブル、クラフトをまとめて組み立てる CPU を追加します。

MEGA Cells が必要です。化学物質セルには Applied Mekanistics、FE セルには AppliedFlux、DISK には AE2 Things が要ります。
