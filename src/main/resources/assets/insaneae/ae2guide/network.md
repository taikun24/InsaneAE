# Cables, Interface and Pattern Provider

## Insane ME Cable

<ItemImage id="fluix_hyper_cable" scale="3" />

A thin cable that carries 128 channels (the `hyperChannels` config). Bus parts can be attached to it like a
smart cable. It comes in all 16 colors and fluix.

<RecipeFor id="fluix_hyper_cable" />

## Compressed ME Dense Smart Cable

<ItemImage id="fluix_compressed_dense_cable" scale="3" />

A dense smart cable made thin: still 32 channels, but bus parts can be attached. It is the step before
the Insane ME Cable.

<RecipeFor id="fluix_compressed_dense_cable" />

## Insane ME Interface

<BlockImage id="insane_interface" scale="3" />

An ME interface with 81 slots that hold up to 2,147,483,647 each. The cable part version drops its
contents when broken.

<RecipeFor id="insane_interface" />

## Insane Pattern Provider

<BlockImage id="insane_pattern_provider" scale="3" />

A pattern provider with 1620 pattern slots. Unlike the Quantum CPU it accepts every kind of pattern and
pushes them out like a normal pattern provider. Processing patterns are pushed in bulk.

<RecipeFor id="insane_pattern_provider" />
